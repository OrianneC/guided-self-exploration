# Guided Self-Exploration

**A structured, psychologically informed self-exploration skill for AI agents.**

Guided Self-Exploration helps AI agents facilitate meaningful, in-depth conversations that support users in understanding themselves more clearly.

Rather than relying on generic personality tests or superficial advice, this skill uses a progressive, conversational interview to explore:

- Core identity and self-concept
- Personal values and needs
- Emotional patterns and coping mechanisms
- Relationships and interpersonal boundaries
- Strengths, blind spots, and internal tensions
- Decision-making styles and personal philosophy
- Future direction and practical growth

## Key Features

- One question at a time, with adaptive follow-up questions
- Evidence-based conversational synthesis
- Clear distinction between observations and hypotheses
- Balanced exploration of strengths and blind spots
- Actionable recommendations and practical exercises
- Privacy-conscious, data-minimizing interaction
- Explicit non-diagnostic and mental-health safety boundaries

## Installation

Copy the `guided-self-exploration/SKILL.md` file into your agent's skill directory and configure your agent to load it when a user requests guided self-exploration.

## Philosophy

The goal is not to tell people who they are.

It is to help them develop a more accurate understanding of themselves through thoughtful questions, careful reflection, and meaningful observations.

**Self-understanding over self-labeling.  
Clarity over reassurance.  
Practical growth over abstract advice.**
